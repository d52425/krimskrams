# P4 キャリア基板（ESP32-P4-POE-ETH / 32088 用）

Waveshare ESP32-P4-POE-ETH（SKU 32088）を載せるキャリア基板。ノード1台分の電源まわりと IR リングのストロボ駆動をこの1枚に集約する。

- 基板サイズ：**86 × 68 mm**、2層（上辺に 8mm の帯を追加し、四隅のネジ穴が 32088 と干渉しないようにした）
- 電源の流れ：32088 の 5V → ポリヒューズ → 入力バルク → **LMR62421 昇圧回路（基板上に直接実装、固定 約11.8V）** → 12V → バルク → MOSFET ローサイドスイッチ → ネジ端子台（TB111）でリングへ
- ストロボ信号：32088 の **GPIO5（ヘッダ物理ピン10）** から取る
- 設計・検証：KiCad 10.0.8、DRC 0 violations / 0 unconnected（`drc_cli.rpt`）
- **未発注**（ガーバーは `gerber/` に生成済み）

## 32088 の載せ方（重要）

- J8 は 2×20 のメスソケット。モジュールの **RJ45 側を基板の左端** に向けて差す（基板シルクの外形線と「ESP32-P4-POE-ETH」の表示が目安、ピン1ドットは RJ45 側・上列の先頭）。
- このモジュールのヘッダは **列ごとに連番**（左列 1–20、右列 21–40、RJ45 側が若い番号）。通常の 2×20（交互配置）とは番号が違うので、J8 は物理ピン番号に合わせた専用フットプリントにしてある。
- キャリア上面図で、上列が物理ピン 1→20（左→右）、下列が 21→40（左→右）。
- 5V の取り出し：物理ピン **40 = VBUS**、39 = VSYS、36 = 3V3。GND は 3/8/13/18/23/28/33/38。公式回路図のネット名では **40 = VCC1_5V、39 = VCC_5V**（下記 SJ1 の項参照）。

## SJ1（5V 選択ジャンパ）

- 1×3 ピンヘッダ（2.54mm、横向き）＋ショートキャップ。中央が負荷側、右が VBUS（pin40）、左が VSYS（pin39）。キャップの差し位置で切り替える（実機検証で両レールを測り比べられる）。
- 公式回路図で確認した実態：**pin40 = VCC1_5V**、**pin39 = VCC_5V**。
- VCC1_5V は、PoE モジュールの 5V 出力（H7 ピン5）と Type-C の USB0_5V → Q2（AO3401）の両方が合流するノード。**PoE でも USB でも 5.0V が立つ。**
- VCC_5V（pin39）は、VCC1_5V から D2（MBR230 ショットキー）を通った後のメイン レールで、ダイオードの Vf 分（約 0.3〜0.45V）だけ低い。
- **デフォルトはキャップを右側（1-2、VBUS = VCC1_5V）** に差す（フル 5.0V が取れる側）。VSYS 側は約 4.6V になるため通常は使わない。
- キャップを差さないと昇圧側は無給電になる（32088 本体は自前の PoE/USB で動くので、止まるのはリング側だけ＝安全側の失敗になる）。

## 昇圧回路（LMR62421、オンボード）

- 秋月 **AE-LMR62421 キットの回路をそのまま基板上に実装**した（別基板モジュールは載せない）。U1 = LMR62421XMF（SOT-23-5）、L1 = 15µH、D2 = SS2040FL。基板西側のシルク枠（30×30mm）が昇圧エリア。
- キットの入出力電解（47µF）は、キャリア側のバルク（入力 C3 470µF／出力 C1 1000µF）が兼ねる。IC 直近の高周波用に 10µF/50V セラミック 1206 を入力（C4/C5）と出力（C6/C7）に各2個。
- **出力電圧は固定**：キットの VR1（50k ボリューム）の代わりに固定分圧（R4 4.7k + R5 18k ／ R6 2.7k）で **約 11.8V**。調整は不要。リングを繋ぐ前に TP2 で確認すること。
- ZD1（BZT52C2V7）はキットと同じ FB クランプ。C8（1000pF）は分圧上側へのフィードフォワード。EN は R7（100k）で +5V にプルアップし常時 ON（給電は SJ1→F1 経由なので、5V を止めれば昇圧も止まる）。
- レイアウト：スイッチングループ（U1 − L1 − D2 − 出力セラミック）は昇圧エリア内に短く収めた。FB 分圧は +5V フィード線（y=35.8）と交わらないよう基板南東に置き、FB 配線は南側を回して U1 に戻している。
- はんだ付けの難所は U1（SOT-23-5、0.95mm ピッチ）だけ。他は 1206 と SOD-123 級。フットプリントは U1 のみ手はんだ用（パッド長め）にしてある。
- 12V ラインの想定上限は **最大 18V**（基板にシルク表示あり）。リング FRS5CC の仕様上限は 15V で、18V は短パルス前提のオーバードライブ上限。ただし本基板の昇圧は固定 11.8V なので、この上限は FET・コンデンサ側の耐圧表示として残してある。

## テストポイント

- TP1 = +5V（ポリヒューズ後段）
- TP2 = +12V（昇圧出力・リング接続前にここで電圧確認）

## 注意・未検証

- 実機の 32088 で VBUS/VSYS の実電圧と、PoE 給電時の 5V レールの余裕（P4 本体＋昇圧入力＋カメラ系）は未検証。
- 昇圧回路のスイッチングノイズがカメラ画像へ与える影響は実機確認待ち（共通 GND 前提）。オンボード化したため、モジュール版より配線は短いが、実測での比較は未実施。
- モジュール（32088）自体の固定はヘッダの摩擦のみ。輸送・振動環境では別途押さえを検討。
- FRS5CC は CDS（光センサ）をバイパス済みにしておくこと（電圧がかかれば点く状態にする）。
