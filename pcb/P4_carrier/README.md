# P4 キャリア基板（ESP32-P4-POE-ETH / 32088 用）

Waveshare ESP32-P4-POE-ETH（SKU 32088）を載せるキャリア基板。ノード1台分の電源まわりと IR リングのストロボ駆動をこの1枚に集約する。

- 基板サイズ：**86 × 68 mm**、2層（モジュール側に 8mm の帯を追加し、四隅のネジ穴がモジュールと干渉しないようにした）
- 電源の流れ：32088 の 5V → ポリヒューズ → 入力バルク → **AE-LMR62421 昇圧モジュール（30×30mm、別基板を上に載せる）** → 12V → バルク → MOSFET ローサイドスイッチ → JST-XH でリングへ
- ストロボ信号：32088 の **GPIO5（ヘッダ物理ピン10）** から取る
- 設計・検証：KiCad 10.0.8、DRC 0 violations / 0 unconnected（`drc_cli.rpt`）
- **未発注**（ガーバーは `gerber/` に生成済み）

## 32088 の載せ方（重要）

- J8 は 2×20 のメスソケット。モジュールの **RJ45 側を基板の左端** に向けて差す（基板シルクの外形線と「ESP32-P4-POE-ETH」の表示が目安、ピン1ドットは RJ45 側・上列の先頭）。
- このモジュールのヘッダは **列ごとに連番**（左列 1–20、右列 21–40、RJ45 側が若い番号）。通常の 2×20（交互配置）とは番号が違うので、J8 は物理ピン番号に合わせた専用フットプリントにしてある。
- キャリア上面図で、上列が物理ピン 1→20（左→右）、下列が 21→40（左→右）。
- 5V の取り出し：物理ピン **40 = VBUS**、39 = VSYS、36 = 3V3。GND は 3/8/13/18/23/28/33/38。公式回路図のネット名では **40 = VCC1_5V、39 = VCC_5V**（下記 SJ1 の項参照）。

## SJ1（5V 選択ジャンパ）

- 3パッドのソルダージャンパ。中央が負荷側、上が VBUS（pin40）、下が VSYS（pin39）。
- 公式回路図で確認した実態：**pin40 = VCC1_5V**、**pin39 = VCC_5V**。
- VCC1_5V は、PoE モジュールの 5V 出力（H7 ピン5）と Type-C の USB0_5V → Q2（AO3401）の両方が合流するノード。**PoE でも USB でも 5.0V が立つ。**
- VCC_5V（pin39）は、VCC1_5V から D2（MBR230 ショットキー）を通った後のメイン レールで、ダイオードの Vf 分（約 0.3〜0.45V）だけ低い。
- **デフォルトは中央＋上（VBUS = VCC1_5V）をブリッジ** して使う（フル 5.0V が取れる側）。VSYS 側は約 4.6V になるため通常は使わない。
- 両方同時にブリッジしないこと（VCC_5V と VCC1_5V が短絡し、D2 をバイパスしてしまう）。

## 昇圧モジュール（AE-LMR62421）の載せ方

- シルク枠（30×30mm）の中に、モジュールの取付穴 **A（Ø3.0、24×24mm ピッチ、四隅 3mm 入り）** に合わせて M3 スタンドオフで固定する。スタンドオフ高さはモジュール裏面部品を避けて 6mm 以上。左下の穴（H3）はキャリアの四隅固定穴と共有で、他の隅穴と整列している。
- **端子台は付けない。メザニン直結**：モジュールの CN1/CN2 の穴（Ø1.3）の真下にキャリア側の穴（J3/J4、Ø1.5）が開いており、Ø1.2mm のピンを両方の基板に通してはんだ付けする。リード線配線が不要になり、端子台の高さ（約10mm）も消える。
- **モジュールの向き**：電解コンデンサのある側を 32088 側（シルク「CAP SIDE」の側）に向ける。極性はマニュアルの配線図で確認済みで、両端子とも **上の穴が＋、下の穴が GND**（CN1：上 = Vin+、CN2：上 = Vout+）。キャリア側も同じ並び（J3 ピン1 = +5V、J4 ピン1 = +12V）。
- 組み立て順：キャリアの J3/J4 にピンを差す → モジュールをスタンドオフに載せてねじ止め → モジュール上面でピンをはんだ付け → キャリア裏面でもはんだ付け。ピン長は約12mm（スタンドオフ 6mm 前提）。モジュール交換時はピン4本のはんだを外す必要がある。
- モジュール側の出力設定は **12.0V**（VR1 を 18kΩ 固定に換装した場合はそのまま。未換装ならボリュームで 12.0V に合わせ、リングを繋ぐ前に TP2 で確認）。
- 12V ラインの想定上限は **最大 18V**（基板にシルク表示あり）。リング FRS5CC の仕様上限は 15V で、18V は短パルス前提のオーバードライブ上限。

## テストポイント

- TP1 = +5V（ポリヒューズ後段）
- TP2 = +12V（昇圧出力・リング接続前にここで電圧確認）

## 注意・未検証

- 実機の 32088 で VBUS/VSYS の実電圧と、PoE 給電時の 5V レールの余裕（P4 本体＋昇圧入力＋カメラ系）は未検証。
- 昇圧モジュールのスイッチングノイズがカメラ画像へ与える影響は実機確認待ち（共通 GND 前提）。
- モジュール（32088）自体の固定はヘッダの摩擦のみ。輸送・振動環境では別途押さえを検討。
- FRS5CC は CDS（光センサ）をバイパス済みにしておくこと（電圧がかかれば点く状態にする）。
