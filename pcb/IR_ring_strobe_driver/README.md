# IRリング ストロボ駆動基板（GPIO → MOSFET 12Vパルススイッチ）

天網（ESP32-P4ノード）用。P4 の GPIO（3.3V）で Nch MOSFET を駆動し、FRS5CC IR LED リング（12V / 200mA）への 12V ラインをローサイドでパルススイッチする小基板。昇圧側は常時 ON で 12V レールを維持する前提で、本基板はバルクコンデンサとスイッチだけを持つ（キャリア基板へ統合する前の単体検証用）。

- 基板：40×30mm、2層、部品は表面のみ、M2 取付穴×3
- 入力 J1（2.54mm 1×3 ピンヘッダ）：pin1 = +12V、pin2 = GND、pin3 = STROBE（GPIO 入力）
- 出力 J2（JST-XH B2B-XH-A）：pin1 = リング＋（+12V）、pin2 = リング−（FET ドレイン）
- TP2 = ゲート電圧テストポイント

## 回路

```
 +12V ──┬── C1 1000µF/25V ── GND
        ├── C2 10µF ──────── GND
        └── J2.1 リング＋
 J2.2 リング− ── Q1 D
 GPIO ── R1 100Ω ── Q1 G、R2 10kΩ で GND へプルダウン、TP2
 Q1 S ── GND
```

- パルス電流は C1（＋C2）から供給する。配線ループ（C1 → J2 → リング → Q1 → GND → C1）を短く配置した
- Q1 は Vgs=2.5V で Rds(on) が規定されたロジックレベル品を使うこと（3.3V 駆動で確実に飽和させるため）。Vds は 12V＋昇圧スパイクに対して 30V 級
- 負荷は LED＋抵抗で誘導性ではないためフライバックダイオードは不要
- リング側 FRS5CC は CDS をバイパス（ショート）して「12V が来れば点灯」にしておくこと
- 駆動タイミング（FW 側）：GPTimer / MCPWM 等のハードウェアタイマで、露光開始の 100µs 以上前に ON、幅＝露光＋マージン
