# IRリング ストロボ駆動基板（GPIO → MOSFET 12Vパルススイッチ）

天網（ESP32-P4ノード）用。P4 の GPIO（3.3V）で Nch MOSFET を駆動し、FRS5CC IR LED リング（12V / 200mA）への 12V ラインをローサイドでパルススイッチする小基板。昇圧側は常時 ON で 12V レールを維持する前提で、本基板はバルクコンデンサとスイッチだけを持つ（キャリア基板へ統合する前の単体検証用）。

- 基板：30×30mm、2層、M2 取付穴×4（四隅）。受動部品はスルーホール実装（Q1 のみ SOT-23 面実装）。部品は C1・C2・Q1・R1・R2 を x=15mm の縦一列に配置（C1 は 90° 回転、抵抗は横向き）
- 入力 J1（ターミナルブロック 3.5mmピッチ 3極、基板左端の上下中央）：上から pin1 = +12V、pin2 = GND、pin3 = STROBE（GPIO 入力）。シルク表示「+12V / GND / STR」
- 出力 J2（ターミナルブロック 3.5mmピッチ 2極、基板右端の上下中央）：上が pin2 = リング＋（+12V）、下が pin1 = リング−（FET ドレイン）。シルク表示「R+ / R-」
- 改訂（2026-11-27）：コネクタをピンヘッダ／JST-XH からターミナルブロックへ変更（圧着不要にするため）。基板サイズ 30×30mm は不変
- 改訂（2026-11-27）：部品配置を中央の縦列（C1・C2・Q1）に変更。J2 のピン割り当てを 上=+12V / 下=ドレイン に入れ替え
- 改訂（2026-11-27）：部品を x=15mm の縦一列配置に変更（C1 は 90° 回転）。TP2 を削除し、取付穴を四隅 4 つに。OUT ブロックは上下中央に配置

## 回路

```
 +12V ──┬── C1 1000µF/25V ── GND
        ├── C2 10µF ──────── GND
        └── J2.2 リング＋
 J2.1 リング− ── Q1 D
 GPIO ── R1 100Ω ── Q1 G、R2 10kΩ で GND へプルダウン
 Q1 S ── GND
```

- パルス電流は C1（＋C2）から供給する。配線ループ（C1 → J2 → リング → Q1 → GND → C1）を短く配置した
- Q1 は Vgs=2.5V で Rds(on) が規定されたロジックレベル品を使うこと（3.3V 駆動で確実に飽和させるため）。Vds は 12V＋昇圧スパイクに対して 30V 級
- 負荷は LED＋抵抗で誘導性ではないためフライバックダイオードは不要
- リング側 FRS5CC は CDS をバイパス（ショート）して「12V が来れば点灯」にしておくこと
- 駆動タイミング（FW 側）：GPTimer / MCPWM 等のハードウェアタイマで、露光開始の 100µs 以上前に ON、幅＝露光＋マージン

## ファイル

- `IR_ring_strobe.kicad_pro / .kicad_sch / .kicad_pcb`：KiCad 10 プロジェクト（プロジェクトローカルの lib テーブル同梱。回路図のみ旧形式で、開いて保存すると 10 形式へ移行）
- `gerber/`：ガーバー9点＋ドリル＋ジョブファイル（発注可）
- `wiring_diagram.png`：昇圧モジュール込みの全体結線図（生成元 `draw_wiring.py`）
- `preview_*.pdf / preview_pcb_top*.png`：プレビュー
- `netlist.txt`：設計意図のネット一覧
- `build_design.py`：生成スクリプト（再生成用、KiCad 同梱 Python で実行）。生成後に `kicad-cli pcb drc --refill-zones --save-board` でゾーン充填と DRC、`kicad-cli pcb export gerbers / drill` でガーバー出力
