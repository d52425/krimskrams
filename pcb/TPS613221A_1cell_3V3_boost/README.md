# 単セル → 3.3V 昇圧基板（TPS613221A）

電池1本（単3/単4、アルカリ 1.5V / NiMH 1.2V）から 3.3V を作る昇圧基板。
専用小基板として設計（30×20mm、2層、部品は片面のみ）。

## 仕様・要点

- IC: **TPS613221A**（3.3V固定出力）。ENピンが無い常時ON構成なので、電源の入り切りは **SJ1（ハンダジャンパ）をブリッジするか**で決める。待機電流は IC の Iq 6.5µA typ が下限。
- 起動電圧 0.87V max（負荷250Ω以上時）。取り出せる電流は入力電圧で決まる：データシート試算例で 0.9V入力時 約114mA。電池終盤は 50–80mA 級が目安。
- J1（2.54mm 1×3ピンヘッダ）：**1 = BAT+ / 2 = GND / 3 = +3.3V出力**。そのままユニバーサル基板やブレッドボードに挿せるモジュール形。
- テストポイント：TP1 = BAT（SJ1の後段）、TP2 = SW波形、TP3 = +3.3V。
- 取付穴：M2 ×3（H1/H2/H3）。

## レイアウト方針

- 電池 → L → SWピン、VOUT → C2/C3 → GND のループを最短に配置。SWノードの銅箔は最小限。
- 裏面は GND ベタ全面、表面も GND ポア（ゾーン充填済み）。GND は各所ビアでスチッチ。
- 出力（+3V3）は基板外周を回して J1 pin3 に戻す配線。
