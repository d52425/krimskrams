# models/

Blender で作る 3D モデルの置き場。

- 使用ソフト：Blender **5.2.4 LTS**（headless / bpy スクリプトで生成・編集）
- ソースは `.blend`、配布・利用向けの書き出しは `glTF (.glb)` / `FBX` / `STL` など、用途に合わせてモデルごとのフォルダに入れる
- 画像から 3D 化したモデルもここに入れる（元画像と生成方法をモデルごとの README に残す）

## モデル一覧

| モデル | 内容 |
|---|---|
