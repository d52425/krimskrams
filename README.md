# 雑貨（Krimskrams）

小物基板や実験データの寄せ集めリポジトリ。
ドイツ語で雑貨・がらくたの寄せ集めは **Krimskrams**（クリムスクラムス）。

## pcb/

KiCad 10 で設計した基板データ。

| 基板 | 内容 | 状態 |
|---|---|---|
| `pcb/IR_ring_strobe_driver/` | 天網ノード用 IR リング（秋月 FRS5CC, 850nm）のストロボドライバ。12V ラインを MOSFET でローサイドスイッチ、バルク 1000µF＋10µF | DRC 違反0（KiCad 10.0.8） |
| `pcb/TPS613221A_1cell_3V3_boost/` | 単セル（単3/単4）→ 3.3V 昇圧（TPS613221A）。電源スイッチは SJ1 ハンダジャンパ | DRC 違反0（KiCad 10.0.8、未接続1件は SJ1 開放分で仕様どおり） |

各基板フォルダに回路図・基板データ、生成スクリプト（`build_design.py`）、ガーバー、プレビュー、DRC レポートが入っている。

※ 基板の発注はまだ行っていない。
